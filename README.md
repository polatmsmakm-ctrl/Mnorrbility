# Mnorrbility

تطبيق ملاحظات للآيباد والآيفون مع دعم كامل لقلم أبل.

**من إعداد وتطوير راشد الشمري**

## المميزات

- الكتابة بقلم أبل وبالإصبع وبأي قلم عبر PencilKit، مع خيار «قلم أبل فقط» لرفض راحة اليد.
- استيراد ملفات PDF والكتابة عليها، والتصدير إلى PDF أو صورة.
- وضع داكن كامل يشمل الصفحات والحبر، مع عكس ذكي لصفحات PDF.
- مجلدات ملوّنة، مفضلة، بحث، ومحذوفة مؤخراً.
- قوالب صفحات (مسطّرة، مربعات، نقاط، كورنيل، نوتة) ووضع التمرير المتصل.
- جلسات مذاكرة بمؤقت دراسة واستراحة.
- المراجعة الذكية: بطاقات حفظ وكويز وملخص لأهم النقاط تتولد تلقائياً لكل مذكرة (حتى ملفات PDF المستوردة)،
  على الجهاز بدون إنترنت، أو عبر Claude بمفتاح المستخدم لقراءة أدق تشمل خط اليد.
- ترتيب الخط والأشكال الذكية، وإرفاق الصور داخل المذكرة وصفحات PDF.
- كل البيانات محفوظة على الجهاز، ولا يُرسل شيء للخارج إلا إذا فعّلت Claude في المراجعة الذكية بنفسك.

## البناء

كل دفعة إلى الفرع `main` تبني ملف IPA وتشغّل اختبارات الواجهة على محاكي آيباد وآيفون،
وتُنشر النتائج (الملف والصور والتقارير) في الفرع `builds`.
يُثبَّت الملف على الجهاز عبر Sideloadly (iOS 17 أو أحدث).
